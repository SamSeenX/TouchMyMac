# SCOPE: Feature Roadmap

## In Scope (v1.0.0 Core)
* Manifest V3 unpacked Chrome extension.
* Popup UI (`popup.html`) with live viewport capture, title input, folder selector, labels, and Save button.
* Dashboard tab (`dashboard.html`) displaying responsive card grid with preview thumbnails.
* Folder management and label tagging.
* Client-side search and filtering by folder, label, domain, and title.
* Netscape Bookmark HTML import and export.
* SaveIt JSON backup and restore.

## Out of Scope (Future)
* Cloud syncing accounts.
* Paid features or analytics.
* Direct bookmark syncing with third-party cloud services.
