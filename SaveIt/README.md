# SaveIt: Visual Bookmark Manager

SaveIt is a privacy-first, zero-dependency Chrome extension built on Manifest V3. It captures crisp visual thumbnail previews of saved webpages, preserves folder hierarchies and labels, and provides universal import and export capabilities across modern web browsers.

## Core Features

* **Quick-Save Popup**: Preview the live tab snapshot, edit titles, pick folders, and attach tags before saving.
* **Instant Visual Dashboard**: High-resolution thumbnail grid with quick search, folder navigation, and tag filters.
* **Universal Import and Export**: Seamlessly import bookmarks from Chrome, Firefox, Safari, Edge, and Arc via standard Netscape HTML format or SaveIt JSON backups.
* **Zero Cloud Lock-in**: Offline-first storage in native browser IndexedDB. No external servers, analytics, or trackers.
* **Sub-200 Line Architecture**: Strictly modular Vanilla JavaScript (ES6 modules) and custom CSS properties with zero third-party dependencies.

## Installation in Chrome

1. Clone or download this repository.
2. Open Google Chrome and navigate to `chrome://extensions`.
3. Enable **Developer mode** using the toggle switch in the top-right corner.
4. Click **Load unpacked** and select this directory.
5. Pin the SaveIt icon to your browser toolbar.
